# calcwell-privacy

Public web of **Calcwell**, a financial calculator for iPhone (RPN and algebraic). To be served at
<https://calcwell.baltajmn.dev/> by GitHub Pages from `main`, behind Cloudflare (CNAME `calcwell` to
`baltajmn.github.io`, proxied), like `humwell-privacy`. Not published yet: no repository, no DNS.

| Path | What it is |
|---|---|
| `index.html` | What the app does, price, support contact. Support and marketing URL in the App Store |
| `privacy/` | Privacy policy. The URL in the app's paywall, Settings and the App Store |
| `legal.html` | Legal notice (LSSI art. 10), same owner details as the other apps' webs |
| `cw/` | Stylesheet and icons |

Terms of use are Apple's standard EULA. The price on `index.html` ($9.99 once) must follow the App Store one.
The app's code lives in `~/AndroidStudioProjects/Calcwell`.
